# Install

Use the repository marketplace at https://github.com/ilanvkn/av3x-antartica. From its checked-out root run `codex plugin marketplace add . --json`, then `codex plugin add android@av3x-antartica --json`. Open a refreshed chat. See docs/WALKTHROUGH.md and docs/MCP.md for setup, standalone MCP and troubleshooting. The legacy .codex-plugin manifest is retained as a supported compatibility format; the package is not an OpenAI directory approval.
