With an existing Node 22+, run `node scripts/atlas.mjs status` or `node scripts/atlas.mjs lookup gpu-frame-engine-lab`. `node scripts/mcp-server.mjs --stdio` starts local MCP. No npm runtime dependencies, API key or network search is needed for retrieval.

The optional `scripts/scaffold.mjs` creates maps source at an explicit empty output. It does not build, install or operate a device. Actual SDK/JDK/build/runtime work is separate. Read examples/maze-map/README.md before using its controlled lab fixtures or adding a service.
