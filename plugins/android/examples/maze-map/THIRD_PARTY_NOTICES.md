# Third-party notices and service boundaries

- MapLibre Native Android13.7.1: BSD2-Clause. https://github.com/maplibre/maplibre-native/tree/android-v13.7.1 . SDK consumer rules and native libraries are distributed through the published Maven artifact.
- OpenFreeMap: MIT hosting/project implementation and provider-hosted default Positron/Dark styles; underlying included-project/style licenses remain applicable. https://openfreemap.org/ and https://openfreemap.org/quick_start/ . Attribution: ©OpenMapTiles; data from ©OpenStreetMap contributors. Default style source remains provider-hosted; the user can request one bounded native offline region (policy limits and completion must be checked).
- OpenStreetMap data: Open Database License. https://www.openstreetmap.org/copyright . The app shows credits; the map's built-in attribution also retains provider source attribution. Initial raster experiment used OSM standard tiles; final vector build uses OpenFreeMap. https://operations.osmfoundation.org/policies/tiles/ applies to that retained initial experiment, not a claim of final raster use.
- Nominatim public geocoding usage policy: https://operations.osmfoundation.org/policies/nominatim/ . Historical Maze0.1 used this public endpoint. Revision02 removes it from the generated source and requires explicit provider configuration. The policy restricts generic LLM/no-code integrations; a proxy does not waive those terms.
- OSRM backend: BSD2-Clause; public HTTP API https://project-osrm.org/docs/v5.24.0/api/ and demo policy https://github.com/Project-OSRM/osrm-backend/wiki/Api-usage-policy . A public demonstration endpoint has no production availability guarantee. Routing weights/ETA are not current traffic. Revision02 uses a retained, attributed KL Sentral–KLCC response only as a labelled local fixture; the lab gateway makes no upstream calls. See tools/fixtures/provenance.json. Production requires a separately reviewed service.
- AndroidX/Compose: Apache2.0; Kotlin: Apache2.0; OkHttp: Apache2.0; org.json in local unit tests: see upstream JSON-java license. Preserve upstream license metadata and notices in distributed artifacts. No private keys or SDK credentials are bundled.

Original sample app source is MIT licensed by this public release. Third-party dependencies, data and service terms remain separate.
