Long investigations need durable evidence, not just a chat summary. Save artifact hashes, exact commands or structured parameters, results, failures, unresolved questions and process cleanup state. Resume by validating those files before repeating work.

**Our example:** the JADX dependency download resumed from partial bytes, then passed the pinned full-file hash. A durable job recorded completion and cleanup. A runtime mismatch was fixed using an existing compatible Node only inside the case; no global configuration change was needed.
